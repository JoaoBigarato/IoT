Requisitos para o Projeto de Automação - Dashboard e Envio de Dados
Este projeto consiste em automatizar o monitoramento de uma máquina usando ESP32 para coletar dados de tempo de operação e contagem de peças, e enviar esses dados para um banco de dados PostgreSQL via uma API FastAPI. A comunicação entre os dispositivos é feita utilizando MQTT e HTTP.

1. Requisitos de Instalação
1.1. No Orange Pi/Servidor (API FastAPI e PostgreSQL)
Instalar Python 3 e dependências

Instale o Python 3 (versão 3.6 ou superior) e o pip:

bash
Copiar
sudo apt update
sudo apt install python3 python3-pip
Instalar dependências do Python

Instale as bibliotecas necessárias para FastAPI, Uvicorn, SQLAlchemy e psycopg2 (para conexão com PostgreSQL):

bash
Copiar
pip install fastapi uvicorn psycopg2-binary sqlalchemy databases
Instalar PostgreSQL

Instale o PostgreSQL:

bash
Copiar
sudo apt update
sudo apt install postgresql postgresql-contrib
Verifique se a instalação foi bem-sucedida:

bash
Copiar
psql --version
Criar Banco de Dados e Tabela

Crie um banco de dados no PostgreSQL e a tabela monitoramento:

sql
Copiar
CREATE DATABASE nome_do_banco;
CREATE TABLE monitoramento (
    id SERIAL PRIMARY KEY,
    tempo_ligada INT,
    tempo_desligada INT,
    contagem_pecas INT,
    horario TIMESTAMP
);
1.2. No Mosquitto (Broker MQTT)
Instalar Mosquitto

Instale o Mosquitto (Broker MQTT) no servidor:

bash
Copiar
sudo apt update
sudo apt install mosquitto mosquitto-clients
Configuração do Mosquitto

O Mosquitto irá rodar em localhost na porta 1883 por padrão. Se precisar alterar a configuração, edite o arquivo de configuração:

bash
Copiar
sudo nano /etc/mosquitto/mosquitto.conf
Reinicie o Mosquitto para aplicar as mudanças:

bash
Copiar
sudo systemctl restart mosquitto
1.3. No Node-RED
Instalar Node-RED

Instale o Node-RED para processar dados e enviá-los via HTTP:

bash
Copiar
sudo apt update
sudo apt install nodered
Iniciar o Node-RED

Inicie o Node-RED com:

bash
Copiar
node-red-start
Acesse a interface do Node-RED através de http://localhost:1880.

Instalar Nós para MQTT e HTTP

No Node-RED, instale os nós necessários para MQTT e HTTP:

node-red-contrib-mqtt (para MQTT).

node-red-contrib-http-request (para HTTP).

1.4. Código da API Python (FastAPI)
O código Python que usa o FastAPI e SQLAlchemy para processar os dados e gravá-los no banco de dados PostgreSQL já foi fornecido anteriormente.

1.5. Rodar a API
Use o Uvicorn para rodar a aplicação FastAPI:

bash
Copiar
uvicorn app:app --reload
A API será acessível em http://127.0.0.1:8000.

2. Requisitos para o ESP32 (Arduino)
Configurar o Ambiente de Desenvolvimento (Arduino IDE ou PlatformIO)

Instale o Arduino IDE ou configure o PlatformIO para programar o ESP32.

No Arduino IDE, adicione a plataforma ESP32 em Ferramentas → Placa → Gerenciador de Placas e busque por esp32.

Instalar Biblioteca MQTT (PubSubClient)

No Arduino IDE:

Vá em Sketch → Incluir Biblioteca → Gerenciar Bibliotecas e busque por PubSubClient.

No PlatformIO, adicione a biblioteca no platformio.ini:

ini
Copiar
lib_deps = PubSubClient
Código para o ESP32

O código C++ que envia os dados via MQTT para o Mosquitto já foi fornecido anteriormente.

3. Fluxo de Dados
Arduino (ESP32) envia dados via MQTT para Mosquitto:

O ESP32 envia os dados (tempo de operação, contagem de peças, etc.) via MQTT para o Mosquitto.

Mosquitto envia via MQTT para o Node-RED:

O Mosquitto repassa as mensagens recebidas do ESP32 para o Node-RED.

Node-RED envia via HTTP para a API Python (FastAPI):

O Node-RED recebe os dados e envia uma requisição HTTP POST para a API FastAPI.

API Python (FastAPI) envia dados para o PostgreSQL:

A API FastAPI recebe os dados e os envia para o banco de dados PostgreSQL via SQL.

4. Teste do Sistema
Teste a Conexão do ESP32 com o Mosquitto.

Verifique o recebimento dos dados no Node-RED.

Teste o envio via HTTP para a API FastAPI.

Verifique se os dados estão sendo gravados no PostgreSQL.
